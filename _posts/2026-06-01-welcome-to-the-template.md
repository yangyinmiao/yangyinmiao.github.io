This starter is designed to help you publish fast and keep writing over time.

Use long posts like this for:

- Tutorials
- Case studies
- Design notes
- Reflections on things you built

The homepage already highlights your latest work, so you do not need to maintain a separate landing page for every update.

## Suggested workflow

1. Write a post in `_posts`
2. Add a short note in `_notes`
3. Add project context in `_projects`
4. Update `about.md` when your focus changes

Keep the site small at first. A good personal blog feels alive because it is easy to update, not because it has a lot of moving parts.
