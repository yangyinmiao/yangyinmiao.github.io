This repository is a reusable starter for a personal blog on GitHub Pages.

## What's included

- Responsive homepage
- Markdown posts
- Notes and project collections
- About page
- 404 page
- Light and dark themes

## Why this exists

Many personal sites either look nice but are hard to maintain, or are easy to maintain but feel unfinished.

This template tries to sit in the middle: expressive, readable, and practical.

## Good fit for

- Developers
- Designers
- Writers
- Anyone who wants a steady publishing habit
